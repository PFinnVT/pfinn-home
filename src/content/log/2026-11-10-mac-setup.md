Up to now, I’ve made every change through the GitHub website. That works, but it means uploading a file just to see what it looks like. The next step is working on my sites right on my laptop, so I started setting up the tools.

- **Node.js and npm** run the tools that build my Astro sites. npm is how you install the add-ons a project needs.
- **Git** keeps track of every change to a project. It’s the same thing GitHub uses, just running on my Mac.
- **Configuring Git** means telling it my name and email so my changes are signed. I used GitHub’s private “noreply” email so my real one stays hidden.

## Things that tripped me up

- In Terminal, a command that prints nothing usually worked. I kept waiting for a “Success!” that never came.
- Typing commands exactly matters. One missing space or quote and Terminal doesn’t know what I mean.

Next up: connecting Git to my GitHub account, copying my homepage to the laptop, and seeing it live at localhost before anyone else does.
