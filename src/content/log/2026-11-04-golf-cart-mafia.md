Not everything has to be useful. Golf Cart Mafia is one page with a title and a drawing: two kittens in fedoras and sunglasses riding a red lifted golf cart, with a violin case on the back seat. It lives at joke.pfinn.org.

- **SVG** is a way to draw pictures with code: shapes, lines, and colors written out as text. The whole drawing is inside the page, with no image file at all.
- **Google Fonts** gave me the old-movie title lettering by adding one line to the page.
- **Plain HTML** means there’s no build step. Vercel just shows the file exactly as I uploaded it.

## Things that tripped me up

- For a plain HTML site, Vercel needs the Framework Preset set to “Other” when you import it.
- A brand-new GitHub repo with no README doesn’t show the Add file button. Instead there’s a small “uploading an existing file” link.
- Getting the kittens to look like they were sitting in the cart, and not floating above it, took more tries than I’d like to admit.
